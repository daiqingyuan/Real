# Real

Real 是一款 macOS 桌面工具，把程序坞窗口收起、灵动岛、音乐与悬浮歌词整合在一个应用中。

当前版本：**1.1.0（构建 3）· 紧凑版**。

## 下载与安装

在本仓库的 [Releases](../../releases) 下载 DMG 或 ZIP。仅支持 **Apple 芯片 Mac、macOS 14 及以上**。

打开 DMG，将 Real.app 拖入“应用程序”，推出映像后从“应用程序”启动。首次使用按引导设置权限。已有用户先退出旧版再替换。

此分发包使用本地代码签名，**尚未经过 Apple Developer ID 签名及公证**。若系统阻止启动，请参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，无需关闭系统安全保护。

## 功能

- 程序坞图标点击收起当前桌面的应用窗口组，再次点击恢复同一组。
- 灵动岛：音乐、系统提示、日历与提醒、文件暂存、镜子与闲置显示。
- QQ 音乐／网易云播放信息、控制与同步歌词；自动跟随最近开始播放的应用。
- 歌词色盘、字号、加粗、背景与单曲同步调整，长句滚动，鼠标悬停自动避让。
- 原生紧凑设置、固定窗口与滚动内容、设置搜索和应用排除。
- 可记忆的程序坞／菜单栏图标选择、登录启动、首次授权引导、运行自检、诊断导出和卸载。
- 保留系统播放器及 YTMDesktop 连接、授权与五个控制位置设置。

关闭设置窗口或隐藏图标不会结束后台；完全停止请使用“退出 Real”。

## 本地构建

需要 macOS、Xcode 及其命令行工具。仓库包含原生 Swift 源码、测试、资源及固定版本的 MediaRemoteAdapter 预编译框架。

    ./build.sh --ad-hoc

结果在 build/real-debug-adhoc.zip。此模式使用临时签名，仅适合开发验证，不继承正式应用身份对应的系统授权。完整原生自测需要桌面会话；--headless-tests 会明确跳过原生滑块测试。

默认 ./build.sh 使用开发机现有本地签名身份，其他电脑没有该证书时请使用上述 --ad-hoc。仓库不包含私钥、个人偏好、播放器令牌或调试记录。
